# sing-box-extended

Sing-box with extended features.

## 🔥 Features

### 🌐 Protocols
- WARP
- MASQUE
- MTProxy
- Mieru
- VPN
- Bond
- Fallback

### 🚦 Limiters
- Bandwidth Limiter
- Connection Limiter

### 🛡 Encryption & Obfuscation
- Amnezia 2.0
- VLESS encryption

### 🔄 Transports
- mKCP
- XHTTP

### 🛠 Services
- Admin Panel
- Manager
- Node Manager

### ⚙ Miscellaneous
- Link parser
- SDNS (DNSCrypt)
- Extended WireGuard options
- Unified Delay

## 📚 Examples

Configuration examples are available here:

https://github.com/shtorm-7/sing-box-extended/tree/extended/examples
